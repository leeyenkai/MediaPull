# Audit 2026-11-21, round 8: metadata edits and Edit/Frame

Same scope and split as rounds 1 to 7 ([1](2026-11-21-1.md) to [7](2026-11-21-7.md)), with fresh auditors told to test
round 7's three rules (faces, edit files, recipes) hard. Totals: 0 critical, 4 majors, 18 minors. Video and audio had no
major. The rules held; what was found were gaps in carrying them out, each fixed within the rule.

## Majors

| ID | Finding | Fix | Proved by |
|---|---|---|---|
| A8-1 | Undo or Redo of a renumbering (names through temporary names) left every photo's `.xmp` hidden: the per-Undo folder listing was not refreshed as files moved into it | A folder's listing is dropped whenever a file moves into it | `testUndoOfARenumberingLeavesNoXMPHidden` and two more |
| A8-2 | Undo of a copied folder split units: a rated photo went to the Trash without its `.xmp`, a Live Photo lost its clip | Within a copied folder, a changed or added file keeps its whole unit | `testUndoOfAFolderCopyKeepsARatedPNGWithItsXMP`, `…LivePhotoWhole` |
| A8-3 | Regrouping counted as a correction and outranked a person's Not This Person on rekey | Only a person's corrections (merge, split, Not This Person) are dated (D-126 amended) | `testARegroupNeverOverridesAPersonsCorrectionOnRekey` |
| B8-1 | A new recipe took the identity of a newcomer at its file's name after a Finder rename (from B7-1) | A new recipe takes the file's identity only when it is the file it was made for (same creation date) | `testB8AFirstKeptRecipeStaysWithTheFileItWasMadeFor` |

## Minors

Fixed: A8-4 (a face corrected before dates were kept outranks one never corrected), A8-5 (a copy beside another photo's
`.xmp` can be undone), A8-6 (a case-only rename of a unit puts the `.xmp` name's case back); B8-2 (⌘Z under an id merged
into the file's recipe reaches that recipe), B8-3 (no recipe is kept for a file no longer there; Paste says so), B8-5
(Flip mirrors the crop, keeping the part chosen), B8-6 (smaller PNG and HEIC exports are opaque to their edges and, from
an opaque photo, have no alpha channel), B8-7 (the Style picker names the face drawn), B8-8 (a recipe another window
wrote while a file opened is kept), B8-9 (a reload during a drag restarts the drag's ⌘Z), B8-10 (Paste counts and says
files it could not keep); C8-1 to C8-3 (a track's media range leaves out the empty edit a late start is stored as, so
fades start where the media does, parts with no picture are refused and a video whose picture starts late opens), C8-4
(the last 40 ms can be cut: only the last part ending at the measured end runs open), C8-5 (MKV and WebM are not offered,
the system cannot read them), C8-6 (a comment). Also: the app's `.xmp` cache forgets moved paths.

Recorded and left (minor, no edit lost): B8-4 (at quit a window's unsaved new recipe can be written beside the file's
recipe instead of into it; the newer is shown), a free crop is dropped on a quarter turn (⌘Z brings it back).

## Checked and fine (from the reports)

Round 7's rules hold: edit files never taken while another photo of the name stays, carried on Redo, followed after
another app's safe save, a single rated copy kept; one recipe per file, adoption, the windows told of every write, ⌘Z
by id, paste onto the open file; fade ramps that never overlap (180,000 random builds and 1,100 exports over ten kinds of
file with late, short, gapped and variable-rate tracks: no crash, every composition valid). Frame rates kept, depth kept
through filters, the build's component check, originals never written, all export and probe work off the main actor.
