# Audit 2026-11-18, round 7

Round 6 was closed in commit 01b9eb1. Three independent auditors read the code (two also ran probes in their scratch
folders: disk images to measure folder numbers, and the journal driven as the app drives it). The brief, as in round 6,
asked for every sibling path of each round-6 closure and for defects the fixes introduced. Findings two auditors made are
listed once, with both ids. Every finding was checked against the code before it was fixed.

## Unproven

- File numbers on FAT or exFAT volumes may change on remount; the volume UUID rule then keeps a record (no loss) but a
  new folder at a trashed folder's path there could reuse it.
- Web-extracted Instagram items carry no owner id and are saved into a selected account folder unchecked.
- History and `followFolderMoves` decode every journal; not measured with a year of large journals.
- gallery-dl's GraphQL paginator ending on a page with no edges (carried).

## Test runs

`check.sh` passed in full (214 package tests, both bridge suites, conformance, lints, both builds, the offline update
self-test with the new refusal and folder-following steps). The web self-tests (`--selftest-edit`) did not start in four
of six launches this round: the process stayed idle and never opened its window, while the Debug app opened earlier for
screenshots was still running under the same bundle id. Launches seconds apart behaved differently, so the cause is not
settled; the `--selftest-edit` step for C7-M2 is to be run again with no other copy of the app open.

## Why majors still appear

Three of round 7's majors were made by round 6's own fixes (a device number assumed stable; path rewriting that ignored
whether the thing at a path was the same thing; a shortcut keyed by item id). The fixes this round were chosen to remove
machinery where possible and to be proved by tests that drive the code as the app does (the journal through
run/undo/redo with following, the self-test through the app's own routes), and the auditors' probe scenarios are now
regression tests.
