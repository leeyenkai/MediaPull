# Audit 2026-11-18, round 16

Round 15 was closed in commit 6913270. Three independent auditors read the code. A and C ran the real bridge against the
bundled yt-dlp with a made-up site (no network), and B probed moves between two scratch disk images. Findings two
auditors made are listed once, with both ids. Every finding was checked against the code before it was fixed.

## What changed in approach

Retry by video id (rounds 14 and 15) failed twice more: an error may name the list rather than a video, and a limit can
stop yt-dlp before a failed video is reached. D-100 removes it. A playlist's Retry Failed runs the list again and
downloads only what is not saved yet, within what is left of "At most", so nothing has to be matched. Undo and Redo jobs
had a size threshold that read a stale copy of the change; every Undo and Redo is now a job, as every change is.
