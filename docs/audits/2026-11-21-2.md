# Audit 2026-11-21, round 2: metadata edits and Edit/Frame

Same scope and auditors' split as round 1 ([2026-11-21-1.md](2026-11-21-1.md)), with fresh auditors who first verified
round 1's fixes. Totals: 1 critical, 6 majors, 31 minors. Three of the majors came from round 1's fixes themselves, and
were answered by simpler rules written into the spec (AUDIT.md: no patching a patch).

## Critical

| ID | Finding | Fix | Proved by |
|---|---|---|---|
| B2-1 | The Frame tab crashed when the frame was removed while it was shown (`\.frame!` bindings) | Bindings that read `frame?` (`EditModel.frameValue`) | `--selftest-edit-photo` (frame removed on the Frame tab) |

## Majors

| ID | Finding | Fix | Proved by |
|---|---|---|---|
| A2-1 | Remove Location then ⌘Z lost the GPS height, heading and time (round 1's A1-11 removed them; Undo keeps the position only) | Simpler rule: Remove Location removes the position only (R-4501 amended); A1-11 reverted | `testRemovingALocationRemovesThePositionAndUndoPutsItBack` |
| A2-2 | Analysis followed edited files only after the whole batch; a stop part way re-ran models and dropped corrections | Each file is followed as soon as it is replaced (`editMetadata(replaced:)`, D-126 amended) | `--selftest-edits` |
| B2-2 | A recipe was deleted after MediaPull moved its file to another disk (a new creation date) | Moves take the new creation date; recipes are never deleted except by Revert (D-127 amended) | `testRecipesAreNeverDeletedAndFollowTheirFiles` |
| B2-3 | Pruning at launch deleted recipes of files on a card that is not the one they were made on | No pruning (D-127 amended) | same test |
| B2-4 | A new file taking an edited file's old name deleted that file's recipe, though it had only been renamed | The recipe follows its reference; it is never deleted on a mismatch | same test |
| C2-1 | ffprobe guesses the length of a VBR MP3 without a Xing header and of ADTS AAC, so cuts and fades were wrong on them | The length is measured from the packets (`FFmpeg.measuredLength`) | `testTheBundledEngineEditsAudio` (MP3 without Xing) |
