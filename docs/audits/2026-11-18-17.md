# Audit 2026-11-18, round 17

Round 16 was closed in commit 93cd7a4. Three independent auditors read the code. A and C ran the real bridge against the
bundled yt-dlp with a made-up site (no network), B probed moves between disk images, a 10,000-file rename take-back and a
web view sharing the window's undo manager. Findings two auditors made are listed once, with both ids. Every finding was
checked against the code before it was fixed.

## Findings

### Major

| # | Finding | Closed by |
|---|---|---|
| A17-M1, C17-M1 | "At most N was reached, so videos that failed were not tried again" appeared when nothing failed (the Retry flag was set on the first run too) | Only failures of this run, and earlier failures a Retry did not come to, are named; nothing when none failed. `testOnlyFailuresNotReachedAreSaidNotTried` |

| C17-M2 | An Undo or Redo of a name swap stopped between its halves left files hidden | They never stop while an item is under a temporary name. `testAStoppedSwapNeverLeavesFilesHidden` |
