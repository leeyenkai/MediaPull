# Review 2026-11-22: visible tools (D-132)

One review of the UI change that follows the person's brief: Edit/Frame's tools as tabs, Export as a bar, the font
list in the Inspector, direct editing on the canvas and the timeline, quiet secondary icons and pane surfaces across the
app. An independent reviewer read the change, not the reasoning behind it. As asked, this is a single review, not the
multi-round audit of [AUDIT.md](../AUDIT.md).

## Fixed

| Finding | Fix |
|---|---|
| The title bar's Undo in Edit/Frame could undo a file operation made in Organise or the Library (they share the window's undo manager) | Undo and Redo there act only on Edit/Frame's own steps ("Edit", "Paste Settings", "Revert Edits") and follow every undo change |
| Layer actions used the row's position, which another window's change could make wrong or out of range | Every layer action finds the layer by id |
| A drag cut short by its overlay going away (Before, a zoom) left the change open, so later edits stopped being undone one by one | The overlays end an open drag when they go away |
| A double-click on a text layer from another tab did not put the cursor in its text | The request waits until the text field is shown |
| Duplicate was only in a context menu | A Duplicate button on the chosen layer's row |
| "Extra at the Bottom" seemed stuck past the border's limit | Its range follows the border, as the border's does |
| Hidden sections' canvas and layer list stayed in the key loop | Focusable only while Edit/Frame is shown |
| Layer rows could not be chosen with VoiceOver | The name has an action that chooses the layer |
| The Organise tree shrank to its top-level folders even when they were opened | It shrinks only when the folder has no folders inside |
| The audio waveform did not follow the playhead when zoomed | The scroll target is placed by padding, not an offset |
| Found while taking the screenshots: the Canvas header's zoom, Before and size did not appear (read from an unobserved property), and an inactive window could show a hover outline | Read from the preview; hover outlines only in the window in front |

## Recorded and left

- Menus kept for rare commands (arranging panes, the narrow-pane overflow, a Library folder's commands, sort and zoom
  choices), as D-132 now says.
- At 4× the canvas enlarges its 2,400-pixel copy rather than drawing the original.
- "Import N New" counts files not imported before; a file of the same name and size already in the destination is still
  skipped when importing, so fewer may be copied than the button says.
- On a kept part narrower than 14 points the two handles overlap.
