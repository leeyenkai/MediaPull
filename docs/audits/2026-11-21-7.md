# Audit 2026-11-21, round 7: metadata edits and Edit/Frame

Same scope and split as rounds 1 to 6 ([1](2026-11-21-1.md) to [6](2026-11-21-6.md)), with fresh auditors who first
verified round 6's fixes. Totals: 1 critical, 9 majors, 14 minors.

Most majors came from round 6's own fixes, in the three areas that had been patched round after round. Under the
protocol's rule against patching a patch, each is answered by one simpler rule written into the spec, replacing the
earlier ones:

- **Faces (D-126):** one content has one set of faces, shared by every file that holds it; when faces are carried onto
  content already held, the newest change wins. Rules about which file holds what (A4-2, A5-2, A6-3) could not satisfy
  both mirror cases (A6-3 and A7-5).
- **Edit files (D-120):** on Undo and Redo of a move a photo's `.xmp` and `.aae` follow it by name once its unit has
  moved, never while another photo of that name stays; a copy beside which an edit file was made stays whole.
- **Recipes (D-127):** a file has one recipe at a time; every window showing a file shows its recipe again when another
  writes it; a new recipe knows its file when first kept; Finder renames are followed while the drive stays connected.
