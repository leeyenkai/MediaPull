### C minor findings in full

- C11 Find Missing on a folder with a stored cursor does not clear it (`continuing || storedCursor == nil` false), so a continuation from the old cursor runs after a full walk.
- C12 startUpdate filters content to profile media and startPull then stores those reduced options as the account's remembered choices.
- C13 lastUpdate stamped on failed, cancelled and blocked runs.
- C14 addKeys only after the loop: keys of files saved before a crash or quit never reach the record.
- C15 narrowed() steps into a lone non-type subfolder (alice/ holding only alice/2024 → alice/2024).
- C16 When the account folder is a library root, the layout comes from its parent (not in a library) → default layout.
- C17 One unrecognised word makes AddressInput.several reject the whole paste; bare usernames too.
- C18 Typing, Services or a dropped link during Download All replaces the list while the batch runs on.
- C19 Services with no window drops the text.
- C20 Batch rename: freeDestination treats names about to be vacated as taken ("1 2.jpg"); preview leaves {date} empty.
- C21 Bare usernames with a dot are read as web addresses.
- C22 Update button not disabled while that folder's job is blocked or paused, or a queued Downloads pull targets it.
- C23 Check Folder lists files saved without metadata on purpose (video thumbnails, D-56 WebM/M4A) as missing it.
- C24 Trash Extra Copies uses the root-wide report: it can trash copies in other folders, including other account folders; the confirmation does not say so; their records keep the keys.
- C25 igp positional keys assume carousel numbers never shift; gallery-dl renumbers after removals.
- C26 A continuation re-lists reels, stories and highlights in full.
- C27 Account folder records never pruned.

Unproven: bookmark resolution following a trashed folder into ~/.Trash; Finder tag changes not refreshing the listing; Services
with multi-line text reading only the first URL; carousel children carrying the parent's code; /var vs /private/var paths;
newlines pasted into the single-line field.
