# Review 2026-11-18, round 29 (1.8 release review)

A final review of everything merged into 1.8 for D-107 to D-113, at commit 3bcdf61, before the 1.8 release. Three
independent reviewers: R1 FileOps, notes and file details (D-107, D-109, D-110); R2 profile views and post details
(D-111 to D-113); R3 integration and release. Save As (D-108) had its own rounds (24 to 28) and was not reopened. Every
finding was checked against the code before it was closed.

## Findings

### Major

| # | Finding | Closed by |
|---|---|---|
| R1-M1 | Undo of a Replace sent the edit to the Trash even when the original could not come back (gone from the Trash, its folder gone, or its name taken) | Undo refuses first and keeps both. `testUndoOfAReplaceKeepsTheEditWhenTheOriginalIsGone` |
| R2-M1 | A pull refused because the name now belongs to another person still wrote that person's profile into the folder's record | The profile is kept only after the id check passes, and never on a refused pull |
